# Cave-to-Cave
### A Stone Age Delivery Service

**Cave-to-Cave** is a free, non-commercial HTML5 browser game inspired by the classic **Ugh! (1992)**.

Built from scratch using vanilla JavaScript and HTML5 Canvas, the game brings prehistoric passenger transportation to modern browsers, combining recreated classic levels with an endless supply of procedurally generated challenges.

🎮 **[Play in Browser](https://xanmk3.github.io/cave-to-cave-play/)**

### Features

- Gameplay inspired by the original Ugh! (1992), aiming to preserve its feel and core mechanics without striving for an exact reproduction
- A growing collection of recreated classic levels, with plans to add more over time
- Procedurally generated levels with platforms, obstacles, and passenger destinations
- Custom-made graphics
- Modern menus and user interface designed from scratch
- Keyboard and touchscreen controls for desktop and mobile devices
- Playable directly in a web browser
